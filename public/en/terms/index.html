2. The service

Webskan is an automated audit of a publicly accessible website specified by the Customer. It covers performance (Lighthouse), technical SEO, accessibility (axe-core, WCAG 2.1 AA), security (TLS, redirects, HTTP headers), broken links (up to 150 links from the start page) and an AI-generated list of prioritised recommendations. The result is a PDF report e-mailed to the Customer. The report is digital content not supplied on a tangible medium.
